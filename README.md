Документация – Онлайн Магазин

Този проект представлява прост онлайн магазин, който създадох с ASP.NET Core, Razor Pages и SQL Server. Целта беше да направя работещо приложение, което позволява управление на продукти, категории, количка и завършване на поръчки.

1. Какво реализирах в проекта
* Продукти и категории

Създадох модели за продукти и категории, като всеки продукт има:

име

описание

цена

снимка

наличност

категория

Категориите и продуктите имат пълен CRUD – може да се добавят, редактират, изтриват и разглеждат.

Добавих и филтър по категории, както и страница за детайли на продукт.

* Количка

Направих количка, която:

показва добавените продукти

смята общата сума

позволява премахване на артикули

работи чрез отделен CartService

Създадох и малък API контролер (CartController), който връща брой продукти в количката и преглед на съдържанието ѝ. Това се ползва от JavaScript на клиента.

* Завършване на поръчка

Създадох Checkout страница, където потребителят въвежда:

име

телефон

адрес

имейл

След това:

се създава поръчка,

добавят се продуктовите позиции,

смята се тотала,

данните се записват в базата,

количката се изчиства.

* База данни

Използвах Entity Framework Core.

Направих DataSeeder, който добавя примерни категории и продукти.

2. Как е структурирано приложението
Модели: Product, Category, CartItem, Order, OrderItem, CheckoutModel
Сервизи: CartService и OrderService
API контролер: CartController
Razor Pages:

продукти – CRUD

категории – CRUD

количка

checkout

изглед за поръчки

Всичко е под Area/Identity, за да бъде разделено добре.

3. Как работи приложението

Потребителят разглежда продуктите.

Може да филтрира по категории или да види детайли.

Добавя продукт в количката чрез AJAX.

Количката показва всички продукти и тотал.

При Checkout потребителят попълва данните си.

Създава се поръчка и се запазва в базата.

4. Използвани технологии

ASP.NET Core 8 + Razor Pages

Entity Framework Core

SQL Server

Bootstrap

JavaScript + Fetch API

ASP.NET Identity (по желание)

5. Заключение

Проектът е прост, но напълно функционален онлайн магазин, който аз изградих сам. Поддържа управление на продукти и категории, работа с количка, API за динамични данни, страница за поръчка и записване на информацията в базата.
